# HireOS Written Test Prototype

## Run locally

Open `hireos-assessment-prototype.html` directly in a browser, or serve this folder with any static HTTP server:

```bash
python3 -m http.server 8743
```

Then open:

```text
http://localhost:8743/hireos-assessment-prototype.html#/tasks
```

The prototype uses simulated data and local browser storage. No backend service is required for the standalone demo.

## Included files

- `hireos-assessment-prototype.html` — runnable Written Test prototype
- `Written_Test_Agent_Conversation_Flow.md` — English Agent dialogue interaction flow
