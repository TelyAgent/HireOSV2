# 互联网公司岗位描述样本

本目录用于 HireOS 面试项目的 JD 上传、AI 解析和候选人匹配测试，模拟一家综合性互联网公司的多职能岗位场景。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `01-高级前端工程师-消费者增长平台.txt` | 与高级前端工程师简历高度匹配 |
| `02-测试开发工程师-质量保障部.txt` | 与测试开发工程师简历高度匹配 |
| `03-SRE工程师-基础设施部.txt` | 与 SRE 工程师简历高度匹配 |
| `04-用户增长经理-市场增长部.txt` | 与用户增长经理简历高度匹配 |
| `05-视觉设计师-品牌设计部.txt` | 与视觉设计师简历高度匹配 |
| `06-商务拓展经理-商业化部.txt` | 与商务拓展经理简历高度匹配 |
| `07-HRBP-人力资源部.txt` | 与 HRBP 简历高度匹配 |
| `08-数据分析师-数据智能部.txt` | 用于测试不同职能方向的低匹配结果（无对应简历） |

## 建议测试方式

1. 先单独上传任意一份 JD，确认职位名称、职责和任职要求能够被 AI 正确提取。
2. 再分别关联 `互联网公司简历样本/` 中的 7 份简历，观察高匹配和低匹配岗位的差异。
3. 使用 `08-数据分析师-数据智能部.txt` 与已有简历关联，验证低匹配场景下 AI 给出的差距分析是否合理。
4. 检查每一条 AI 解析结果是否有原文引用，并在人工核对后保存。
