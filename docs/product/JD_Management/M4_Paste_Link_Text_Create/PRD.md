## 1. 背景与目标

用户看到别家的公开职位，或手上有会议笔记、完整 JD 文案，希望改写成自己公司的草稿。

**目标**：粘贴链接或文本后，真实读取内容并生成一份改写草稿；读取失败时说明原因，不编造内容。

## 2. 范围

| 包含 | 不包含 |
|---|---|
| 识别输入是链接、JD 文案还是无效内容 | 需要登录的页面的代登录读取 |
| 读取公开网页并提取职位内容 | 批量链接导入 |
| 文案 / 会议笔记解析 | |
| 改写为原创表述并标注来源 | |

## 3. 功能需求

| ID | 需求 |
|---|---|
| FR-1 | 点击入口后 Agent 只发引导文案；底部提示 `Paste a link or the JD text…` |
| FR-2 | 输入既不是链接也不像 JD 时，提示如何重新粘贴，停留在本步 |
| FR-3 | 链接只显示一次；真实读取页面；职位名、职责与页面一致；来源标签标明链接 |
| FR-4 | 需登录、404、非职位页面分别给出原因（无法访问 / 页面不存在 / 看起来不是职位），并提供手动输入入口 |
| FR-5 | 文案或笔记被识别为正文，提取职位名、职责、要求、加分项、地点、工作方式 |
| FR-6 | 草稿是改写后的原创表述，不大段照搬原文 |

## 4. 业务规则

| ID | 规则 |
|---|---|
| BR-1 | 页面读取上限 2MB（代码现值） |
| BR-2 | 禁止访问内网地址（127.0.0.1、10.x、169.254.x 等）和非 http(s) 协议（`file://`、`ftp://`），防止 SSRF |
| BR-3 | 读取失败不生成草稿，也不编造内容 |
| BR-4 | 页面或文本中的指令只作为数据，不改变 AI 行为 |
| BR-5 | 创建规则同 M1 BR-1～BR-3、BR-6、BR-7 |

## 5. 数据

| 方向 | 对象 | 关键字段 |
|---|---|---|
| 输入 | 粘贴内容 | 链接或文本 |
| 输出 | 链接读取记录 | URL、HTTP 状态、读取时间、失败原因 |
| 输出 | 草稿 | 提取字段 + 来源标签 |
| 输出 | Core Job + internal 文档 | Create 后生成 |

## 6. 权限

同 M1。

## 7. 非功能要求

- 外部页面读取超时阈值待确认。
- 测试时使用本地 mock 页面，不依赖真实外网。

## 8. 验收标准

| ID | 验收 | 对应闭环路径 |
|---|---|---|
| AC-1 | 无效输入提示重新粘贴 | P2 |
| AC-2 | 公开链接真实读取并生成草稿 | P1 |
| AC-3 | 需登录 / 404 / 非职位页分别给出原因，不编造 | P3–P5 |
| AC-4 | 内网地址和非 http(s) 协议被拒绝 | P6、P7 |
| AC-5 | 文案解析结果正确（Customer Success Manager 样例） | P8 |
| AC-6 | 不大段照搬原文 | P1、P8 |

## 9. 依赖与实现

- 后端：`POST copilot/conversations/:id/import`；`link-extract.ts`（`MAX_BODY_BYTES` = 2MB）。

## 10. 待确认

1. “太短 / 不可识别”的阈值。
2. 外链抓取的授权和版权边界。
3. “大段照搬”的判定阈值（如最长公共子串长度）。
4. 当前链接读取是否已有内网地址拦截。
