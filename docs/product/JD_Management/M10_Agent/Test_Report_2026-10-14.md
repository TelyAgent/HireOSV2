## 4. 按用户旅程的缺陷与建议

| ID / 级别 | 角色、旅程步骤 | 证据与用户影响 | 最小修复方向与验收检查 |
|---|---|---|---|
| M10-LIVE-01 / **P0** | Recruiter/TA；M10a 问答入口 | E1–E3、E6：右侧提示“可以直接提问”，但无选区的文档问答、审批问题、薪资问题一律要求先选段。用户不能完成 M10 P0 的整份文档问答，也无法知道真正的前置条件。 | 区分“问答无选区”与“改写需选区”；显示 Whole document 和当前模式。复测 V-08、Q-12、SAL-03 分别进入正确处理路径，且无越权扩展上下文。 |
| M10-LIVE-02 / **P1** | Recruiter/TA；M10a 意图识别 | E4：显式“只回答，不修改”仍生成可采纳改写提案；E7 调研答复又附空提案。问答/研究与写入提案混淆，增加误采纳风险。 | 服务端按意图控制输出类型，问答/调研不创建建议；仅改写呈现 diff 与 Apply/Reject。复测 E4/E5/E7，核对 API revision 和建议列表。 |
| M10-LIVE-03 / **P1** | Recruiter/TA；M10b 市场薪资调研 | E7：页面已有地点，答复却称地点未指定；调研仅拿到单段薪酬上下文，没有完整画像。用户无法判断薪资结论所用画像，容易把信息不足误解为职位资料缺失。 | 调研使用当前职位获授权的完整画像，并显式展示已知/缺失字段；只有真实缺失才追问。用可控来源复测卡片及证据不足分支。 |
| M10-GAP-01 / **P0 验收阻断** | Viewer/Recruiter；M10e 权限与指令隔离 | 缺四角色测试账号、Confidential 与第二 Workspace seed、已登录 API/模型输入/AiRun 记录。无法证明模型未收到受限内容、未跨 Workspace 或未执行附件指令。**没有线上泄露实测证据。** | 提供隔离角色与数据、只读审计入口；按 UC-22/23/24 逐请求检查输入过滤、工具调用和服务端授权。 |
| M10-GAP-02 / **P1 验收阻断** | Recruiter/TA；M10b～M10d 调研与参考起草 | 薪资数据源、对标 mock、公司画像库/seed 缺失，且部分产品口径待确认。UC-12～21 的完整闭环不能在线上验收。 | 先确认优先级、来源、证据阈值和版权阈值，提供隔离桩和可控测试数据，再跑成功/缺失/冲突/不可访问路径。 |

上述 P0/P1 表示对 M10 验收的影响，不等同于已证实生产数据越权。M10-LIVE-01 足以使本次整体结论为 **fail**。

## 5. UX/UI 应用性十项

| 项 | 结论 | 依据 |
|---|---|---|
| U1 容易理解 | **失败** | Copilot 指引说可直接提问，实际要求先选段；未标当前模式/范围。 |
| U2 容易上手 | **失败** | 非改写问题被提示“先选中文字”，无法从空白输入开始问答或调研。 |
| U3 快速完成任务 | **失败** | 问答无法完成；调研被迫先选段，且未得到卡片。 |
| U4 下一步明确 | **失败** | 无选区提示给出错误的下一步；薪资证据不足回复未引导补齐画像/来源。 |
| U5 提示和按钮清楚 | **失败** | “只解释”出现采纳改写；相同薪资文本也给采纳按钮。 |
| U6 符合真实工作方式 | **失败** | 用户不能先问问题再决定是否改 JD；薪资调研路径未闭环。 |
| U7 信息结构符合角色目标 | **未知** | 页面未明确 M10 业务角色；缺多角色账号。 |
| U8 减少跳转与重复 | **部分符合** | 在编辑页可直接使用右侧 Copilot；但问答需额外选段。 |
| U9 可恢复和可预期 | **部分符合** | 提案可拒绝，刷新后抽查原文仍在；失败、网络中断、重试幂等未验证。 |
| U10 可访问、可读和可操作 | **未验证** | AX 有输入框、按钮和文本状态；未执行完整键盘路径、200% 缩放、焦点/读屏检查。 |
