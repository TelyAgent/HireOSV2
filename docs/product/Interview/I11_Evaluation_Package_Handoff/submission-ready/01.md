### Type

Bug

### Subsystem

hireos-interview

### Problem

已发布评估包的 `Export PDF` 按钮只显示模拟导出提示，没有生成或下载 PDF，HR 无法完成独立模式下的评估包存档。

### User Outcome

HR 能导出包含评估结论及确认信息的可阅读、可打印 PDF。

### Scope

I11 评估包 PDF 生成、下载及状态反馈。

### Non-goals

不增加 PDF 以外的导出格式；不实现 Offer 审批或发放。

### Acceptance Criteria

- AC-1: 双方确认后的评估包可导出 PDF，内容包含 Rubric、逐项分数、受控证据引用和双方确认记录。
- AC-2: PDF 使用适合阅读和打印的浅色样式。
- AC-3: 界面分别显示生成失败与下载失败，不将两者混为同一状态。
- AC-4: 自动测试覆盖导出成功、生成失败及生成成功后下载失败。
