### Type

Bug

### Subsystem

hireos-interview

### Problem

未记录决定的项目中 `Evaluation Package` 入口被禁用，提示先记录决定；I11 PRD 要求未记录决定或未双方确认时仍可预览，并标记 `unconfirmed`。

### User Outcome

HR 能在确认前检查包内容，明确知道该包尚不能发布或交接。

### Scope

未确认包的只读预览、状态提示及操作门槛。

### Non-goals

不允许未确认包发布或交接。

### Acceptance Criteria

- AC-1: 未记录决定或未双方确认时，授权用户可以打开包的只读预览。
- AC-2: 预览明确标记 `unconfirmed`，说明阻塞原因，发布与交接不可用。
- AC-3: 自动测试覆盖无决定、单方确认和双方确认三种状态。
