### Type

Bug

### Subsystem

hireos-interview

### Problem

已发布评估包显示 `Sent`，但页面没有 Offer 接收确认、精确包版本或交付记录。用户无法判断下游是否真正收到评估包。

### User Outcome

HR 能明确区分发送中、已接收和失败，并在失败后安全重试。

### Scope

I11 到 Offer 的版本化交接、ACK、失败记录、重试与幂等。

### Non-goals

不实现 Offer 的预算、薪酬、审批或发放。

### Acceptance Criteria

- AC-1: 只有收到 Offer ACK 后，界面才显示“已接收”；仅发起发送不能显示为已接收。
- AC-2: 超时或失败时显示失败原因、未部分发送的说明和重试入口。
- AC-3: 同一包版本重复发送时，Offer 只接收一次。
- AC-4: v2 已接收后到达的 v1 重放不能覆盖 v2。
- AC-5: 自动测试覆盖超时重试、重复发送和乱序到达。

### References

I11 PRD AC-2～AC-4；测试报告 I11-003。
