### Type

Bug

### Subsystem

hireos-interview

### Problem

已发布包的 Human review 显示 HR、Hiring Manager 的确认状态与时间，但未展示具体确认人和确认意见，难以追溯人工复核依据。

### User Outcome

查看评估包的人能知道谁对哪个版本作了确认，以及确认时的意见。

### Scope

双方确认记录的展示及与包版本的关联。

### Non-goals

不改变必须双方确认的规则。

### Acceptance Criteria

- AC-1: Human review 展示 HR、HM 各自的确认人、时间和意见。
- AC-2: 确认记录关联精确评估包版本；修订后旧确认不会被呈现为对新版本的确认。
- AC-3: 自动测试覆盖双方确认、单方确认和修订后的展示。
