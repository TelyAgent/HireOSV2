### Type

Bug

### Subsystem

hireos-interview

### Problem

当前包页没有版本依赖或失效状态；I11 文档将 JD 更新后的需复核和下游通知列为未实现。用户难以判断已交接结论是否仍适用。

### User Outcome

上游依据变化后，HR 能看到需复核状态，Offer 能识别已接收版本失效或受限。

### Scope

JD 更新、数据撤回和录制授权撤回触发的包失效、复核提示及 Offer 通知。

### Non-goals

不自动替 HR/HM 重新确认结论。

### Acceptance Criteria

- AC-1: 相关上游数据变化后，受影响包显示“需复核”及原因。
- AC-2: 已交接版本的失效或限制状态可靠通知 Offer，并保留通知结果。
- AC-3: 重新复核后生成新版本，旧版本仍可只读追溯。
- AC-4: 自动测试覆盖三类上游变化及通知失败后的恢复。
