### Type

Bug

### Subsystem

hireos-interview

### Problem

已发布包头仅显示 Hiring Evaluation Package，未显示包 ID、Version n、来源 Rubric 版本或生成时间，用户无法确认查看与交接的是哪一版结论。

### User Outcome

HR 与 HM 能识别评估包的精确版本，并追溯其来源标准。

### Scope

包版本、内容快照、包头信息和旧版只读访问。

### Non-goals

本草稿不处理证据行内容和 Offer 接收逻辑。

### Acceptance Criteria

- AC-1: 包头显示包 ID、版本、来源 Rubric 版本和生成时间。
- AC-2: 修订生成新版本，旧版本保留只读且不能被覆盖。
- AC-3: 自动测试覆盖版本修订及旧版查看。

I11 PRD FR-3、FR-12；测试报告 I11-002。
