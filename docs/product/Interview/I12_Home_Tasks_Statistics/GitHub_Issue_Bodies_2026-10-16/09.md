### Type

Bug

### Subsystem

hireos-interview

### Problem

本地前端使用当前可访问项目列表计算 Workspace Overview，无法保证部分权限用户看到与全局口径一致的汇总；线上缺双账号与 API 对照，尚未复现越权或错数。

### User Outcome

用户看到统一的 Workspace 汇总，同时明细和详情维持授权过滤。

### Scope

Workspace Overview 聚合数据来源、去重与权限对照。

### Non-goals

不向部分权限用户开放未授权项目详情。

### Acceptance Criteria

AC-1：相同 Workspace 的授权角色按定义看到一致的全局汇总。
AC-2：明细和项目详情仍按记录权限过滤，并解释汇总与明细的范围差异。
AC-3：双账号、跨 Workspace 与多轮项目自动测试核对 API 和数据库主键。
