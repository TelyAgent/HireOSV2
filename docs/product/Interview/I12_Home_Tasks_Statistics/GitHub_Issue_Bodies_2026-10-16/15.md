### Type

Bug

### Subsystem

hireos-interview

### Problem

首页 Task list 的筛选与视图切换区没有项目或候选人搜索入口，记录较多时需要逐行寻找。

### User Outcome

用户可按项目或候选人关键词快速定位任务。

### Scope

首页任务列表搜索控件及两种视图的搜索结果。

### Non-goals

不增加跨模块全局搜索。

### Acceptance Criteria

AC-1：用户可输入项目或候选人关键词筛选任务，清空后恢复原列表。
AC-2：Task list 与 Cluster by JD 的结果遵循同一搜索口径和权限。
AC-3：自动测试覆盖命中、无结果、清空及筛选组合。
