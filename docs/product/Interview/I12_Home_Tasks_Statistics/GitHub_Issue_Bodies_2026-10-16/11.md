### Type

Bug

### Subsystem

hireos-interview

### Problem

本地前端把 More statistics 等偏好保存在单一 hireos_prefs 键中，缺用户和 Workspace 维度；线上仅验证当前会话刷新后保留展开。

### User Outcome

用户返回首页时保留自己的折叠选择，切换身份或 Workspace 不互相污染。

### Scope

首页统计折叠偏好的存储键与切换时恢复。

### Non-goals

不重做全部个人设置系统。

### Acceptance Criteria

AC-1：同用户同 Workspace 刷新或返回首页后保留折叠状态。
AC-2：切换用户或 Workspace 后读取各自偏好，不沿用上一作用域状态。
AC-3：自动测试覆盖两个用户和两个 Workspace 的交叉组合。
