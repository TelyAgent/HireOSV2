### Type

Bug

### Subsystem

hireos-interview

### Problem

项目材料标为 Résumé Not provided，但首页对应任务行仍显示可点击 View résumé；点击只出现 coming soon。

### User Outcome

无附件时用户看到明确弱态；有附件时能真正预览。

### Scope

任务行简历附件状态、入口可用性和预览动作。

### Non-goals

不改变简历上传或解析流程。

### Acceptance Criteria

AC-1：未上传简历的任务行显示 No resume 弱态且不可打开预览。
AC-2：已上传简历的任务行能打开对应简历预览。
AC-3：自动测试覆盖有附件与无附件两条记录，以及两种任务视图。
