### Type

Bug

### Subsystem

hireos-interview

### Problem

My Work 显示固定身份标签，四张个人待办卡为零；本地前端代码把这些指标设为常量，当前会话的真实待办无法据此判断。

### User Outcome

用户看到按本人、角色和 Workspace 计算的待办及正确身份。

### Scope

My Work 身份显示、M01–M04 数据来源与刷新。

### Non-goals

不重定义个人待办的产品口径。

### Acceptance Criteria

AC-1：身份标签与当前登录用户及 Workspace 对应。
AC-2：M01–M04 来自真实作用域数据，受控非零样本显示正确计数。
AC-3：切换用户或 Workspace 后重取，自动测试覆盖隔离。
