### Type

Bug

### Subsystem

hireos-interview

### Problem

展开 More statistics 后，T2 补充指标与 T3 趋势指标混在同一层，用户无法快速理解信息结构。

### User Outcome

用户能区分补充统计和趋势，并了解展开后增加哪些指标。

### Scope

首页补充统计区的信息层级、标题与展开提示。

### Non-goals

不改变统计值的计算方式。

### Acceptance Criteria

AC-1：T2 与 T3 在展开区域有明确分组和标题。
AC-2：展开控件说明额外指标数量，并保持收起/展开操作可用。
AC-3：自动测试或界面验收覆盖展开、收起与返回首页。
