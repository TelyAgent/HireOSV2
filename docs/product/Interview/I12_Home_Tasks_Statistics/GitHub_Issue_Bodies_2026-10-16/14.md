### Type

Bug

### Subsystem

hireos-interview

### Problem

Cluster by JD 的零候选人组提供 Link candidate 按钮，但点击后只显示 coming soon，无法完成关联。

### User Outcome

用户可从零候选人组进入关联候选人流程，并看到关联结果。

### Scope

零候选人 JD 的关联入口、导航与结果反馈。

### Non-goals

不改变候选人去重或匹配算法。

### Acceptance Criteria

AC-1：点击零候选人组的 Link candidate 后进入可用的候选人关联流程。
AC-2：成功关联后分组候选人数和列表更新。
AC-3：自动测试覆盖零候选人入口、关联成功与取消返回。
