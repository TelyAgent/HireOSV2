### Type

Bug

### Subsystem

hireos-interview

### Problem

首页取数尚未结束时，个人与工作区统计卡先显示 0，列表还同时出现 Loading… 与 No projects yet.，用户无法区分加载中和真实零。

### User Outcome

用户能识别取数中的状态，取得结果后才看到真实零或实际计数。

### Scope

首页统计卡、筛选计数与空状态的加载呈现。

### Non-goals

不调整各指标的业务计算口径。

### Acceptance Criteria

AC-1：慢请求期间显示加载态，统计卡和筛选不显示未经确认的 0。
AC-2：请求完成且结果为空时才显示真实零与空状态。
AC-3：自动测试覆盖慢请求、真实零、失败和重试。
