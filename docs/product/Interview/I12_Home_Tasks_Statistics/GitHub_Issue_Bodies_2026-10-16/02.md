### Type

Bug

### Subsystem

hireos-interview

### Problem

点击 Total interview projects 等统计卡后页面和 URL 不变，卡片缺少按钮或链接语义，无法复核汇总对应的记录。

### User Outcome

用户从统计卡进入同口径明细，并仅查看自己有权访问的记录。

### Scope

首页统计卡交互、明细过滤、权限与可访问性。

### Non-goals

不扩大用户对项目详情的访问权限。

### Acceptance Criteria

AC-1：点击或键盘激活统计卡后进入与卡片同口径的明细。
AC-2：部分权限用户可见全局汇总时，明细仅列其有权访问记录并解释差异。
AC-3：自动测试覆盖卡片导航、口径过滤和权限边界。
