### Type

Bug

### Subsystem

hireos-interview

### Problem

本地前端对不同角色使用同一组 HR 项目筛选；线上缺独立 Interviewer 账号，不能将当前账号截图当作 Interviewer 权限证据。

### User Outcome

Interviewer 首页以本人面试、排期确认和评分任务为主，并只能查看授权任务。

### Scope

Interviewer 首页任务筛选、角色化列表和接口权限验证。

### Non-goals

不改变 HR/HM 的项目管理权限。

### Acceptance Criteria

AC-1：Interviewer 首页呈现与本人任务对应的筛选和列表。
AC-2：Interviewer API 不返回未授权项目详情或候选人资料。
AC-3：HR 与 Interviewer 双身份自动测试覆盖 UI 和 API 权限。
