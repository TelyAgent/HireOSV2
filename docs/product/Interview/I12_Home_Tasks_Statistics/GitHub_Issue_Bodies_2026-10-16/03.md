### Type

Bug

### Subsystem

hireos-interview

### Problem

默认 Task list 中 Draft 排在 Interview in progress 前，未遵循任务列表规格的待处理优先级。

### User Outcome

用户打开首页先看到需要处理的任务；筛选后保留既定相对顺序。

### Scope

Task list 默认状态优先级、同级排序和筛选后顺序。

### Non-goals

不改变项目状态本身。

### Acceptance Criteria

AC-1：默认列表按规格的 Action required first 优先级排序，同状态按更新时间倒序。
AC-2：切换筛选后，保留命中行在默认列表中的相对顺序。
AC-3：受控数据自动测试覆盖全部规定状态及同状态更新时间。
