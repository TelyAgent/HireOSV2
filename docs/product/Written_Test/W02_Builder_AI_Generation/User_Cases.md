## 1. 使用说明

- **前置数据 / 测试身份 / 注入点**：定义见 [Written Test README](../README.md#公共约定)。
- **测试数据**：名称与 [Loop_IO.md](Loop_IO.md) 第 2 节一致。
- **AI 输出**：按判定条件检查，不比对固定文字；同一输入至少跑 2 次。
- **状态**：✅ 可测；🟡 部分可测；❌ 未实现（执行时标记 known gap）。
