## 三、当前已确认问题详情

### F-001 — Quick Start 提交后登录服务不可用

- **复现**：Job Library → New job → Quick Start → 输入两行非敏感回答 → Send。
- **实际**：显示 `Sign-in service is unavailable.`；没有第三问追问、草稿或 Workspace。
- **预期**：Agent 收集三问并生成一份可检查的职位草稿。
- **影响**：J1 主流程不可用，并阻断依赖 AI 的 J2/J4/J6。
- **建议**：检查线上 Agent 请求的认证/会话依赖；错误时保留输入并提供 Retry / Back to creation options。

### F-002 — New conversation 未重置失败状态

- **复现**：在 F-001 错误出现后点击 New conversation。
- **实际**：原问题、用户输入和错误仍然保留；不能直接回到五种创建入口。
- **预期**：建立新 conversation，清空消息和步骤状态。
- **建议**：新会话使用新 ID；失败状态增加 Start over，并清除旧会话状态。

### F-003 — AI 错误状态缺少可恢复动作

- **实际**：错误可见，但没有 Retry、服务状态、错误详情或返回入口。
- **建议**：错误卡片提供 Retry 与 Start over；重试必须幂等。

### F-004/F-005/F-014/F-015 — 角色、发布和安全验收前置条件缺失

这些项目目前属于验收阻塞，不应被误判为产品已通过或已失败：缺少多角色账号、测试发布渠道和服务端权限证据。补齐前置条件后，必须重新执行 J7/J8，并检查 Network 响应体而不只是页面隐藏状态。

## 四、优先处理顺序

1. **先修 F-001**：恢复 AI 创建主流程。
2. **同步修 F-002、F-003**：确保错误后可以恢复，不丢输入、不重复创建。
3. **补齐 F-004、F-005**：提供角色账号和安全测试发布渠道。
4. **复测 F-006–F-013**：补全创建、解析、分析、发布和版本闭环。
5. **最后完成 F-016–F-018**：网络并发、无障碍和构建稳定性专项。
