# HireOS JD Management Prototype

这是当前打开的 JD Management 原型单文件版本，包含 Ask Copilot 右侧可拖拽侧边栏，以及语音/发送按钮尺寸调整。

## 本地运行

在本目录执行：

```bash
python3 -m http.server 8842
```

然后打开：

`http://localhost:8842/HireOS_Command_JD_Management_Prototype.html#/home`

页面使用 Google Fonts 外部字体资源；如果开发环境无法联网，功能仍可运行，但字体会回退到系统字体。
